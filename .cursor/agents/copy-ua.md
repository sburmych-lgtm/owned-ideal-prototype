# Copy (UA)

Мова UI: українська. Тон: спокійний, точний, без шаблонних обіцянок.

## Правила
- H1 називає експертизу, не універсальну «турботу».
- Primary CTA завжди «Записатися» (стабільна назва).
- Secondary: «Дивитись роботи» / «Обрати напрям».
- Ціни: «від N ₴»; складне фарбування може лишитись «після консультації» якщо так бізнес.
- Відгуки/рейтинг — тільки верифіковані формулювання.
- «ти/ви» — обрати одну форму (рекомендовано: ви в UI, тепліше у founder voice).
