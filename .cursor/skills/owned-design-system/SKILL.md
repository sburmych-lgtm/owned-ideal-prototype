# Skill: OWNED Design System

Apply `docs/03_DESIGN_SYSTEM.md` literally.

When styling:
1. Pull colors from CSS variables only.
2. Display = Prata; body = Manrope; data = IBM Plex Mono.
3. Neon only on dark surfaces as light.
4. Sharp radii (0–2px).
5. Max 3 motions; honor reduced-motion.

Reject Inter/Roboto/Arial, purple gradients, cream+terracotta defaults unless brief forces them.
