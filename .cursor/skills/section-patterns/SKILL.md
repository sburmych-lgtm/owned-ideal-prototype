# Skill: Section Patterns

Canonical order from `docs/02_IDEAL_FRONTEND_ARCHITECTURE.md`.

Patterns:
- **Hero** — brand + one H1 + lead + CTA group + full-bleed media
- **Trust** — 3–4 mono metrics, one source label
- **Results** — one BA engine + 5–6 cases
- **Services** — families with від ₴, hair primary
- **Visit** — numbered 01–04 only (real sequence)
- **Space** — one chapter, bento
- **Reviews** — quotes + Google
- **Founder** — thesis not bio dump
- **Location+Booking** — friction killer

One job per section. No card-hero.
