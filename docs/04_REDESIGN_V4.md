# 04 · Редизайн v4 — OWNED

**Що це.** Повний редизайн головної сторінки OWNED на базі контенту живого сайту
<https://owned-v2-claude-opus.vercel.app> (Next.js). Реалізовано у `prototype/` як
статичний HTML/CSS/JS — без фреймворку, без зовнішніх залежностей у рантаймі.

Гілка: `claude/beauty-salon-redesign-6b2xni` (паралельна до `main`).

## 1. Що було не так у поточній версії

Аудит живого сайту (desktop 1440 / mobile 390) виявив шість проблем UI:

| # | Проблема | Наслідок |
|---|----------|----------|
| 1 | **Усі 11 розділів на темному тлі** (`#0e100d`) | Немає ритму; розділи зливаються, довгі прайс-таблиці й форма читаються важче, ніж мали б |
| 2 | **Hero:** лід ліворуч унизу, CTA праворуч унизу — на 1440px між ними ≈1000px | Головна дія відірвана від обіцянки; око не веде від тексту до кнопки |
| 3 | **Майстри та відгуки — горизонтальні рейли** | З 8 майстринь видно 2–3; головний доказ експертизи прихований за скролом убік |
| 4 | **Радіуси-пігулки** на кнопках і чіпах | Суперечить `docs/03_DESIGN_SYSTEM.md` §4 (0–2px, editorial sharp) |
| 5 | **`.reveal { opacity: 0 }` без JS-гейта** | Без JS чотири картки «Напрями» лишаються невидимими |
| 6 | **Довжина 12 048px (desktop)** при 11 нумерованих розділах | Запис — після одинадцятого розділу |

## 2. Рішення редизайну

### 2.1 Ритм поверхонь — головна зміна
Розділи чергуються `ink → bone → paper` (`docs/03_DESIGN_SYSTEM.md` §2):
**темне — атмосфера, світле — інформація.**

```
hero(ink) → proof(bone) → 01 напрями(paper) → 02 роботи(ink) → 03 послуги(bone)
→ 04 майстри(paper) → 05 простір(ink) → 06 відгуки(bone) → 07 засновниця(ink)
→ 08 локація+запис(paper) → footer(ink)
```

Компоненти не знають про поверхню: кожна `.surface--*` перевизначає лише
`--bg / --fg / --fg-lo / --rule / --accent`. Неон (`--neon`) лишається **тільки
світлом на темному**, мох (`--moss`) — акцентом на світлому.

### 2.2 Структура: 11 розділів → 8
`Процес` злито з `Простором`, `Визнання` — із `Засновницею`, `Локація` — із `Записом`.

### 2.3 Hero
Один лівий стовпчик: eyebrow → H1 → лід → обидва CTA. Двошаровий скрим
(вертикальний + горизонтальний) тримає контраст тексту незалежно від кадру.

### 2.4 Доказ одразу після героя
Смуга `proof`: 8 майстринь · 17+ років · 70% команди · TOP 100.
Усі чотири числа взяті з контенту живого сайту — нічого не вигадано.
Рейтинг Google **не** показано: на живому сайті його немає, тож вигадувати нічого.

### 2.5 Роботи (до/після)
Двигун порівняння — `<input type="range">` поверх кадру: тягнеться мишею,
пальцем **і стрілками з клавіатури**, має власне ARIA-ім'я. Старт 50%,
одна підказка-помах при першій появі, зупиняється після першої взаємодії.
Шість робіт перемикаються кнопками з `aria-pressed`; блок метаданих —
`aria-live="polite"`, тож зміна озвучується.

### 2.6 Майстри та відгуки
Майстрині — сітка 4×2 на десктопі, 2×4 на мобільному: **видно всіх вісьмох**.
Відгуки — сітка 3×2 від 1080px; на вузьких екранах — snap-рейл
(`docs/02_IDEAL_FRONTEND_ARCHITECTURE.md`, mobile IA: «ВІДГУКИ (snap)»)
з focusable-контейнером для клавіатури.

### 2.7 Прайс
Чотири групи (стрижки · колористика · відновлення · нігтьовий сервіс),
моноширинні цифри, hairline-рядки. Ціни й тривалості — з живого сайту.

### 2.8 Геометрія та шрифти
Радіуси 0–2px, hairline `1px --rule`, Prata / Manrope / IBM Plex Mono.
Шрифти **самостійно розміщені** (`prototype/fonts/`, latin+cyrillic, 8 накреслень,
140KB) — жодного запиту на fonts.googleapis.com у рантаймі.

### 2.9 Рух — рівно три
1. Neon reveal — «ти» в H1 загоряється один раз;
2. BA affordance — помах смуги один раз;
3. Section fade-rise — 620ms при вході у в'юпорт.

Приховані стани живуть **тільки під `.js`** на `<html>`, тож без JS сторінка
повністю читається. `prefers-reduced-motion: reduce` вимикає все.

## 3. Перевірено

| Перевірка | Результат |
|-----------|-----------|
| axe-core (wcag2a/aa, wcag21aa, wcag22aa, best-practice) @390 | **0 порушень** |
| axe-core @1440 | **0 порушень** |
| Без JS | 54/54 `.reveal` видимі; `tel:`, Instagram, онлайн-запис працюють |
| `prefers-reduced-motion: reduce` | анімації вимкнено, контент видимий |
| Горизонтальний скрол @390/768/1024/1440/1920 | немає |
| Порожні клітини у сітках | немає (сітка «Простір» рахована під 2/3/4 колонки) |
| Вирівнювання колонок відгуків, ряд 2 | збігається з рядом 1 (170/537/903px @1440) |
| Якір під шапкою | masthead на 108px (desktop) / 76px (mobile) нижче шапки |
| Клавіатура | видимий фокус на всіх 16 перших зупинках; BA рухається стрілками |
| Форма | валідація, фокус на першому хибному полі, чесний demo-статус |
| CLS / LCP (локально, 1440) | 0.0075 / 188ms |
| Вага першого завантаження | 22 запити · ~1.1MB (з них 889KB — фото) |
| Довжина сторінки | desktop 11 390px (було 12 048) · mobile 15 309px (було 14 389) |

**Свідома компромісна зміна:** мобільна сторінка на ~0.9k px довша за поточну,
бо майстрині показані сіткою, а не рейлом. Вісім спеціалісток — головний доказ
експертизи; ховати шістьох за горизонтальним скролом дорожче, ніж додати екран.

## 4. Межі чесності

- Форма **нічого не надсилає** — це прототип. Про це сказано в UI, поруч —
  живі `tel:`, Instagram і `bookon.ua`.
- Усі тексти, ціни, тривалості, імена майстринь і відгуки взяті з живого сайту.
  Нічого не дописано й не «покращено».
- Робочі години не показані: їх немає у джерелі, вигадувати не можна.
- Медіа скопійовано з живого сайту (`/film`, `/compare`, `/masters`, `/work`,
  `/brand`). Відео-рілзи розділу «Галерея» **не** перенесені — використано їх
  постери; за потреби відео повертається у `prototype/media/work/`.
